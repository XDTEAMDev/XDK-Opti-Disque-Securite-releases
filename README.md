# XDK Opti Disque Sécurité — téléchargements

*(ex « logiciel XDK TEAM DEV » : même logiciel, nouveau nom. XDK TEAM DEV est le nom de l'équipe.)*

Versions téléchargeables de **XDK Opti Disque Sécurité** : analyse, nettoyage et optimisation de disque pour Windows, et vérification de la sécurité du PC.

## Télécharger

1. Ouvre la [dernière version](https://github.com/XDTEAMDev/XDK-Opti-Disque-Securite-releases/releases/latest).
2. Télécharge **`XDKOptiDisqueSecurite.exe`** (le fichier `.sig` à côté sert seulement à vérifier les mises à jour).
3. Lance-le. Il faut le **.NET 8 Desktop Runtime** (x64), gratuit chez Microsoft : https://dotnet.microsoft.com/download/dotnet/8.0

## Clé (gratuite)

Il faut une **clé** pour utiliser le logiciel (essai, 1 mois ou à vie) :

1. Ouvre le logiciel : il affiche le **code de ton PC** (par exemple `ABCD-EFGH-JKLM`). Copie-le.
2. Rejoins le **Discord XDK TEAM DEV** : https://discord.gg/zEC35KSuxt, choisis ta langue, puis va dans la catégorie 💻 XDK OPTI DISQUE SÉCURITÉ, salon 🔑・demande-de-clé.
3. Clique sur « Demander une clé » et colle ton code PC. L'équipe valide ta demande et t'envoie ta clé en **message privé**.
4. Colle la clé dans le logiciel et clique sur « Activer ».

Une clé ne marche que sur le PC de son code. Les mises à jour arrivent toujours toutes seules, même sans clé. Une clé du « logiciel XDK TEAM DEV » marche aussi.

## Mises à jour

Automatiques et obligatoires : à chaque ouverture, le logiciel regarde ici s'il existe une nouvelle version, la télécharge, vérifie sa **signature** et redémarre dessus. Un fichier qui n'est pas signé par XDK TEAM DEV est refusé.
